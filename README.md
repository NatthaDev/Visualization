# Scopus Visualization Dashboard

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the generated GitHub Pages URL.

The dashboard is a static HTML file and uses Plotly from its public CDN. No server or Python is required after deployment.
